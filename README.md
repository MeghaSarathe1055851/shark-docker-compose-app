# shark-docker-compose-app
Docker Compose-based multi-container application integrating Node.js and MongoDB to serve a Shark Info webpage (CSC581 Cloud Computing Assignment).


# Shark Docker Compose App

This project demonstrates a multi-container application using Docker Compose.

## Tech Stack
- Node.js (Express)
- MongoDB
- Docker Compose

## Features
- Connects Node.js app with MongoDB
- Displays Shark Info webpage
- Includes student name in output

## Run Instructions
```bash
docker-compose up --build
